# approval-adjudicator

企业数据网关批量纠错的多人会签审批裁决库。状态持久化在 SQLite（使用 Node.js 内置
`node:sqlite`，无原生依赖），由上层调用。

## 能力

- `createTicket(db, input, now)`：提交工单，1–5 个顺序阶段，每阶段普通/升级审批人集合非空，每轮 24h。
- `submitDecision(db, input, now)`：提交审批决定；决定标识在工单内唯一，重投返回首次受理结论。
- `advanceTime(db, now)`：推进业务时间，所有未结束工单兑现到期转换。
- `getTicket(db, ticketId, now)`：查看工单（终态 / 当前阶段与轮次 / 当前轮已同意人员 / 截止时刻）。

所有接口都接收调用方提供的可信毫秒时刻 `now`，并在处理前落实截至该时刻的到期转换。

## 规则要点

- 当前轮内每人首次有效决定生效，不能改票；普通轮全票同意进入下一阶段，任一有效驳回整单驳回。
- 普通轮到期切升级轮（从原截止时刻起算 24h），已同意清空，升级组重新会签；升级轮到期整单超时。
- 到期与决定同一毫秒时先处理到期；一次跨过两个截止时刻直接超时。
- 受理结论、计票与阶段转换在同一 SQLite 事务生效；同一进程内并发调用等价于某个合法串行顺序。
- 批准 / 驳回 / 超时为不可逆终态；重新打开数据库后状态与去重结论保持不变。

## 构建与测试

```sh
npm install
npm test
```

要求 Node.js ≥ 22.5（内置 `node:sqlite`）。测试使用内置 `node:test`，先由 `tsc` 编译到 `dist/` 再执行。
