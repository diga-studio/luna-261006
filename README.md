# task26100602

学习内容推荐库（纯 Python、进程内存、无外部依赖）。

## 功能

依据学习者的阅读与测验历史，为其推荐接下来适合学习的内容。
学习证据与内容发布状态全部存放在进程内存中，每次修改后立即生效，
下一次查询与基于全部当前数据直接全量计算的结果一致。

## 接口

```python
from learning_recommender import LearningRecommender

r = LearningRecommender()

# 1. 替换某学习者对某内容的当前学习证据（覆盖，不累加）
#    weight: 0=未接触, 1=已读未通过测验, 3=通过测验
r.set_evidence("alice", "content-1", 3)

# 2. 修改内容发布状态（内容初始为未发布）
r.set_published("content-2", True)

# 3. 查询某学习者的前 10 篇推荐内容 ID
recs = r.recommend("alice")  # -> list[str]，不足 10 篇不补齐
```

## 推荐规则

- 每对 (学习者, 内容) 只有一个当前权重；再次提交覆盖旧值，
  改为 0 后该内容重新成为此人的未接触内容，缺失记录按 0 计算。
- 两名学习者的相似度 = 各内容权重乘积之和 /
  双方权重平方和乘积的平方根（余弦相似度），计算使用双方全部内容
  （含已下线内容）；任一方全部权重为 0 时相似度为 0。
- 相似度四舍五入到小数点后 8 位，按此值取相似度大于 0 的
  前 20 名其他学习者作为邻居，同分按学习者 ID 字典序升序。
- 候选内容必须已发布、目标学习者当前权重为 0，
  且至少一名入选邻居对此内容权重大于 0。
- 推荐分 = 所有入选邻居对此内容的权重与其已舍入相似度乘积之和，
  四舍五入到小数点后 8 位；按推荐分降序取前 10，
  同分按内容 ID 字典序升序。
- 先选邻居再筛候选；下线只改变候选资格，不删除学习证据，
  重新上线后立即恢复资格。
