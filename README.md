# learning-recommender

学习内容推荐库（纯 Python，无第三方依赖）。学习证据与内容发布状态保存在
进程内存中，由上层直接调用；每次查询都基于全部当前数据直接计算，任何修改
在下一次查询中立即生效。

## 安装 / 导入

将 `learning_recommender/` 目录放入项目即可：

```python
from learning_recommender import Recommender
```

## API

```python
rec = Recommender()

# 1. 替换某学习者对某内容的当前学习证据（覆盖，非累加）
#    weight: 0=未接触, 1=已读未通过, 3=通过测验；改为 0 后重新成为未接触
rec.set_evidence(learner_id="u1", content_id="c1", weight=3)

# 2. 修改内容发布状态（内容初始为未发布）
#    下线不删除学习证据，重新上线后立即恢复候选资格
rec.set_published(content_id="c2", published=True)

# 3. 查询某学习者的前 10 篇推荐（返回内容 ID 列表，不足 10 篇不补齐）
rec.recommend("u1")  # -> ["c2", ...]
```

调用方需已完成阅读记录归并和测验判定，本库不处理原始事件。

## 推荐规则

- 相似度：双方各内容权重乘积之和，除以双方权重平方和乘积的平方根；
  任一方全部权重为 0 时为 0；计算使用全部内容（含已下线内容），
  结果四舍五入到小数点后 8 位。
- 邻居：相似度大于 0 的前 20 名其他学习者，同分按学习者 ID 字典序升序。
- 候选内容：已发布、目标学习者当前权重为 0、至少一名入选邻居权重大于 0。
- 推荐分：所有入选邻居对此内容的权重与其已舍入相似度乘积之和，
  四舍五入到小数点后 8 位；按分数降序取前 10，同分按内容 ID 字典序升序。
- 先选邻居再筛选候选；没有邻居时返回空列表。

## 运行测试

```bash
python3 -m unittest discover -s tests -v
```

测试包含独立的全量参考实现，与库输出逐项比对，并覆盖：
非共同内容改写使邻居跨越第 20 名边界、内容下线再上线后候选资格正确变化、
随机操作序列下每次修改后与全量重算一致等场景。
