# task26100608

NodeShield 实例熔断与请求准入库（Go）。由上层代理直接调用，状态保存在进程内存中，不实际发送 HTTP 请求。

## 用法

```go
clk := nodeshield.NewRealClock()              // 或注入自定义单调时钟（毫秒）
pool, err := nodeshield.NewPool(ids, clk)     // 固定实例池，至多 500 个

cred, ok := pool.Acquire()                    // 申请转发：在途最少者优先，同数按标识字典序
if !ok { /* 无候选，拒绝 */ }
pool.Report(cred, nodeshield.OutcomeSuccess)  // 回报结果：5xx 与超时算失败
st, _ := pool.Status(id)                      // 查看实例阶段与在途数
```

## 语义要点

- 每实例最多 32 个在途请求；申请成功立即占名额，首次有效回报归还。
- 同一凭据只接受第一次有效回报；重复回报不还名额、不贡献样本。
- 正常阶段按完成时刻统计最近 60 秒（恰 60 秒前的不计）；≥20 样本且失败比例严格 >50% 触发熔断 30 秒。
- 熔断到期进入试探；试探最多一个未结束请求，5 秒未结束按超时处理，从截止时刻起重新熔断 30 秒。
- 旧阶段凭据的迟到回报只还名额，不影响新阶段、样本或计时；每次恢复正常从空窗口开始。
