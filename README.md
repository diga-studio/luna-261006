# CastLine 共享费用分摊库

输入一批共享费用（科目金额 + 面向各部门的万分比整数权重），输出整数分摊矩阵与部门合计，
同时满足**逐科目核平**与**部门汇总尾差控制**，并达到两级字典序最优。

## 使用

```ts
import { allocate } from "castline-allocate";

const result = allocate({
  subjects: [
    { id: "S1", amount: 1n, weights: { A: 3400, B: 3300, C: 3300 } },
    { id: "S2", amount: 2n, weights: { D: 4500, E: 2750, F: 2750 } },
  ],
});
// result.matrix[科目ID][部门ID] -> bigint（分）
// result.departmentTotals[部门ID] -> bigint（分）
```

- 科目、部门均为唯一字符串 ID；部门集合取全部科目权重键的并集。
- 金额为非负 `bigint`（分）；权重为非负整数，每个科目合计 10000，权重 0 的部门该科目必分 0。
- 输入视为已通过业务校验。

## 分摊规则与求解保证

对科目 s、部门 d，理想值 `ideal = amount_s * weight_{s,d} / 10000`。结果矩阵 x 满足：

1. **单格取整**：`x_{s,d} ∈ {⌊ideal⌋, ⌈ideal⌉}`，理想值为整数时 `x_{s,d} = ideal`；
2. **逐科目核平**：每行合计恰等于科目金额；
3. **部门尾差控制**：每列合计 ∈ `{⌊Σ_s ideal⌋, ⌈Σ_s ideal⌉}`（先汇总理想值再取整）；
4. **两级最优**：先最小化 `Σ_d |列合计 − 列理想合计|`，再最小化 `Σ_{s,d} |x_{s,d} − ideal|`。

## 设计说明

### 为什么两个方向的取整约束可以同时成立

把每格写成 `x = ⌊ideal⌋ + y`，`y ∈ {0,1}`。则：

- 行约束：每行需要向上取整的格数 `r_s = amount_s − Σ_d ⌊ideal⌋` 是**确定的整数**
  （权重合计 10000 ⟹ 每行余数合计为整数，且 `r_s` 不超过该行非整数格数）；
- 列约束：列收到进位总数 `f_d ∈ {⌊F_d⌋, ⌈F_d⌉}`，其中 `F_d` 是列内余数之和；
- 总量自洽：`Σ_s r_s = Σ_d F_d`（都等于总金额减去全部下取整），故列上下界整体相容。

理想值本身同时满足全部行、列、格界约束，所以该运输多面体非空；其约束矩阵
（行和、列界、格界，系数全为 0/1 的区间约束）是全单模的，整数数据的运输多面体
必然存在**整数顶点**，即存在同时满足两个方向取整约束的整数矩阵。因此问题必有解，
剩下的只是在其中选最优——这正是最小费用流擅长的事。

### 建模：最小费用流

图：`源 → 科目 → 部门 → 汇`。

- `源→科目` 容量 `r_s`：每行必须发出的进位数；
- `科目→部门` 仅对余数 `rem > 0` 的格建容量 1 的边，流量即 `y_{s,d}`；
  理想值为整数（含权重 0）的格没有边，自然不会被改动；
- `部门→汇` 两条边：容量 `⌊F_d⌋` 的**下取整边**（列约束下界）与容量 1 的**进位边**。

### 两级最优如何用费用量级实现

所有误差放大 10000 倍后都是整数。设总流量为 `F`：

- 单格边费用 `20000 − 2·rem`：每单位流量恰好经过一条单格边，常数偏移不影响比较；
  其非常数部分 `10000 − 2·rem` 正是该格“向上取整 vs 向下取整”的误差增量。
- 部门进位边费用 `BIG·(20000 − 2·colRem)`，其中 `BIG = 20000·F + 1` 大于任何可能的
  单格费用总和（≤ `19998·F`）。列合计取整方向一旦不同，部门误差至少差 1 个最小单位，
  费用差至少 `BIG`，任何单格费用的此消彼长都无法弥补——于是**先**最小化部门合计误差，
  在并列解中**再**最小化单格误差，字典序由费用量级天然保证。
- 下取整边费用取 `−M`（`M` 大于其余所有费用之和），强制其饱和，
  即强制每个部门合计达到列理想合计的下取整，列约束下界由此成立；
  由于 `Σ⌊F_d⌋ ≤ F ≤ Σ⌈F_d⌉`，饱和可行（上节已证）。

求解用连续最短增广路（SSP + 势函数 Dijkstra），增广次数 = 总流量 `F ≤ 科目数 × 部门数`，
图规模 `O(科目数 + 部门数)` 个节点、`O(科目数 × 部门数)` 条边，费用用 `bigint` 精确计算。

## 测试

- `test/disjoint.test.ts`：两个科目的可分摊部门互不相交（1 分按 3400/3300/3300，
  2 分按 4500/2750/2750），验证各组独立核平、余数最大的部门优先进位，并核验两级最优误差值。
- `test/optimality.test.ts`：对至多 4 科目 × 4 部门的实例穷举全部合法矩阵求参考最优，
  逐用例对照 `allocate` 的两级误差；覆盖零权重、整数理想值、零金额、
  以及“部门误差相同但单格误差不同”的并列情形（300 个确定性随机用例 + 手工构造用例）。
